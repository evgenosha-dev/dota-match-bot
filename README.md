# Dota Match Bot

Telegram-бот, который сообщает, что в **Dota 2 найден матч**: уведомление приходит,
как только на экране появляется кнопка «Принять». Дальше бот дополняет сообщение
герояем, командой и итогом матча (K/D/A, длительность, режим), а в уведомлении есть
кнопка «Принять матч» — нажатие нажимает Enter в окне Dota 2.

Бот работает в фоне на том же ПК, где запущена Dota 2: после настройки окно можно
закрыть, ничего больше открывать не нужно.

## Установка (Windows)

Нужны Git и Python 3.10+.

```powershell
git clone https://github.com/evgenosha-dev/dota-match-bot.git
cd dota-match-bot
.\install.bat
```

`install.bat` создаст окружение и запустит мастер настройки. Мастер попросит:

1. Отправить общему боту в Telegram код привязки (`/start КОД`) — уведомления
   будут приходить тебе в личку.
2. Ввести Steam API key (обязательно, берётся на steamcommunity.com/dev/apikey).
3. По желанию — ссылку на Steam-профиль (для итогов и составов матчей).
4. Согласиться на автопринятие и автозапуск — после этого бот стартует сам
   при входе в Windows и работает без окон.

После настройки перезапусти Dota 2 (мастер записывает GSI-конфиг для деталей матча).

Повторная настройка в любой момент:

```powershell
.\.venv\Scripts\python.exe bot.py setup
```

## Друзьям
