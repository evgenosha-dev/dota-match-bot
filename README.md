# Dota Match Bot

Telegram-бот, который сообщает о том, что в **Dota 2 найден матч**.

Бот состоит из агента обнаружения и Telegram-уведомлений. Агент работает на том же
ПК, где запущена Dota 2, и снимает сигнал о найденном матче несколькими независимыми
способами — если один не сработал, сработает другой.

## Как это работает

| Детектор | Что ловит | Когда срабатывает | Нужны доп. настройки |
| --- | --- | --- | --- |
| `accept_button` | Зелёная кнопка «Принять» в центре экрана (анализ скриншота, без привязки к окну) | Когда Dota показывает экран найденного матча; кнопка должна быть на экране 3 опроса подряд (~750 мс) | Только Windows: pillow, numpy, opencv-python, pyautogui |
| `steam` | `game_id` в Steam Web API указывает на Dota 2 | Когда игрок реально зашёл в матч (после accept-экрана); используется для пополнения деталей, а не для уведомления «матч найден» | Steam Web API key + steamid64 |
| `gsi` | Game State Integration от Dota 2 | Когда матч стартовал; также даёт героя, команду и итог матча | Конфиг GSI в каталоге Dota 2 |
| `opendota` | Появился новый матч в истории OpenDota | После завершения матча | account_id в OpenDota |

Поведение уведомлений:

- первое срабатывание детектора отправляет сообщение «Матч найден»;
- повторные сигналы того же поиска **не спамят**: следующее уведомление будет только
  после старта/завершения матча или через 15 минут;
- если позже приходят подробности (герой, команда, match id) — исходное сообщение
  **дополняется** через `editMessageText`, а не дублируется;
- результат матча приходит отдельным сообщением с K/D/A, длительностью, режимом,
  лобби, регионом и счётом;
- после завершения OpenDota дотягивает **составы обеих команд** (ник, герой, K/D/A)
  и по каждому игроку — **топ-3 героя за последние 50 матчей** (сколько раз пикались);
  это же сообщение обновляется на месте, когда детали готовы;
- дубликаты от разных детекторов отсекаются по ключу события и временному окну.

> Составы врагов Dota отдаёт только после матча: GSI как игроку показывает лишь
> твоего героя. Поэтому полный список команд приходит в сообщении о завершении матча.

## Требования

- Windows 10/11 (для детектора `accept_button` и автопринятия; остальное работает везде).
- Python 3.10+ (только для запуска из исходников — exe уже содержит Python).
- Dota 2 и Steam, запущенные на том же ПК.

## Установка из Git (рекомендуется)

Нужны Git и Python 3.10+.

```powershell
git clone https://github.com/evgenosha-dev/dota-match-bot.git
cd dota-match-bot
.\install.bat
```

`install.bat` создаст виртуальное окружение `.venv`, установит зависимости и сразу запустит
мастер настройки. Для повторной настройки потом используй:

```powershell
.\.venv\Scripts\python.exe bot.py setup
```

Если не хочешь запускать мастер сразу, установи зависимости командой `.\install.bat -NoSetup`.

## Установка без установщика

```powershell
git clone https://github.com/evgenosha-dev/dota-match-bot.git
cd dota-match-bot
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python bot.py setup
```

## Быстрый старт (готовый exe)

1. Скачай `dota-match-bot.exe` со страницы **Releases** этого репозитория.
2. Запусти его. При первом запуске откроется тот же мастер привязки Telegram:
   код → Steam API key → профиль (необязательно) → GSI-конфиг → кнопка «Принять матч».
3. Мастер сам создаст `config.json` рядом с exe и отправит тестовое сообщение.
4. Оставь окно открытым (или настрой автозапуск) — бот работает, пока запущен.

Токен общего бота уже настроен. Тебе нужно только привязать свой Telegram аккаунт.

## Настройка

Всё делает мастер:

```powershell
python bot.py setup
```

Он по шагам спрашивает:

1. **Telegram** — использует общий бот **@BflyDotaBot**. Мастер покажет одноразовый код;
   отправь боту команду `/start КОД` и возвращаться в консоль не нужно — мастер сам дождётся
   подтверждения и сохранит `chat_id`.
2. **Steam** — API key (**обязателен**, вставка Ctrl+V работает) и ссылку на профиль /
   steamid64 / account_id (можно пропустить Enter'ом). С профилем дополнительно
   включится OpenDota (результаты и составы матчей).
3. **GSI** — сам находит каталог Dota 2 и записывает конфиг; после этого перезапусти Dota.
4. **Автопринятие** — включает кнопку «Принять матч» в уведомлении.

Повторный запуск мастера безопасен: пустой ввод оставляет текущее значение,
кроме Steam API key — его мастер требует всегда.

### Переменные окружения

Любой параметр можно переопределить переменной окружения — удобно, чтобы не хранить
секреты в файле:

| Переменная | Назначение |
| --- | --- |
| `DOTA_BOT_TELEGRAM_TOKEN` | Токен Telegram-бота |
| `DOTA_BOT_TELEGRAM_CHAT_ID` | Chat ID получателя |
| `DOTA_BOT_STEAM_API_KEY` | Steam Web API key |
| `DOTA_BOT_STEAM_ID64` | steamid64 |
| `DOTA_BOT_CONFIG` | Путь к другому файлу конфига |
| `DOTA_BOT_PAIRING_PATH` | Путь к временному файлу кодов привязки |
| `DOTA_BOT_LOG_LEVEL` | Уровень логирования (`INFO`, `DEBUG`) |

## Как обнаруживается «матч найден»

Уведомление «матч найден» отправляется **только** когда детектор `accept_button`
находит на скриншоте экрана зелёную кнопку «Принять»:

- детектор снимает весь экран и анализирует **центральную область**, где Dota 2
  всегда показывает accept-диалог — никакой привязки к окну, PID или фокусу;
- кнопка должна быть крупной, широкоформатной (пропорции 2:1–9:1) и плотно
  зелёной — это отсеивает карту, миникарту и прочие зелёные элементы;
- кнопка должна оставаться на экране **3 опроса подряд** (~750 мс при шаге 250 мс),
  поэтому одиночный ложный сигнал или мигание интерфейса не приводят к уведомлению;
- повторная эмиссия в пределах 90 секунд подавляется;
- каждые 10 секунд детектор пишет в лог диагностику (размер экрана, число зелёных
  пикселей, число кандидатов) — по ней видно, что детектор работает и что видит.

Старого детектора `foreground` (реакция на переход фокуса на `dota2.exe`) в пайплайне
нет: он давал ложные уведомления при каждом переключении окон обратно на Dota.

## Опционально: GSI (герой, команда, итог матча)

Game State Integration отдаёт данные о матче: героя, команду, счёт, состояние игры.

```powershell
python bot.py gsi-setup
```

Команда сама найдёт каталог `dota 2 beta` в библиотеках Steam и запишет конфиг в
`game/dota/cfg/gamestate_integration/`. Если каталог не найден — укажи его явно:

```powershell
python bot.py gsi-setup --dota-dir "C:\Program Files (x86)\Steam\steamapps\common\dota 2 beta"
```

После этого включи детектор в `config.json`:

```json
"gsi": { "enabled": true, "host": "127.0.0.1", "port": 9977 }
```

GSI работает только в Windows и только когда Dota 2 запущена. Он срабатывает уже
после экрана подтверждения — но даёт самое полезное сообщение: герой, команда,
а по завершении матча — победа/поражение и статистика.

## Автопринятие из Telegram (опционально)

Если бот запущен на том же ПК, где Dota 2 (Windows), уведомление «Матч найден»
приходит с кнопкой **«Принять матч»**. Нажатие отправляет `Enter` в окно `dota2.exe`:

```json
"remote_control": { "enabled": true, "process_name": "dota2.exe", "focus_window": true }
```

- `focus_window`: если Dota не в фокусе, бот сначала переведёт её на передний план.
- `Enter` отправляется только когда `dota2.exe` действительно в фокусе; иначе бот
  вернёт предупреждение и ничего не нажмёт.
- Кнопка доступна только владельцу (`telegram.chat_id`) и убирается после успешного
  принятия.
- Это локальная автоматизация ввода, а не официальный API Valve: используй на свой
  риск. Отклонить матч кнопкой нельзя — для decline нужен клик по кнопке.

## Запуск

```powershell
python bot.py run              # агент + Telegram-бот (основной режим)
python bot.py run --no-telegram  # только детекторы, события в лог
python bot.py detect           # то же самое, отдельная команда
python bot.py setup            # мастер настройки Telegram-части
python bot.py test             # отправить тестовое уведомление
python bot.py status           # состояние из state.json
python bot.py resolve "<url>"  # узнать steamid64 по ссылке профиля
python bot.py gsi-setup        # записать GSI-конфиг в каталог Dota 2
```

Команды бота в Telegram:

| Команда | Действие |
| --- | --- |
| `/start` | Краткая справка |
| `/on` / `/off` | Включение и выключение уведомлений |

### Автозапуск

Для exe создай ярлык в `shell:startup` (Win+R → `shell:startup`) на
`dota-match-bot.exe`.

Для запуска из исходников — задача Планировщика Windows:

```
program:  C:\путь\к\проекту\dota-match-bot\.venv\Scripts\python.exe
arguments: bot.py run
start in: C:\путь\к\проекту\dota-match-bot
```

Задачу можно привязать к событию запуска Dota 2 или к входу в систему.

## Ограничения

- Детектор `accept_button` работает только на Windows и смотрит на экран:
  экран принятия должен быть виден, то есть Dota 2 не должна быть свёрнута
  полностью под другие окна во время поиска матча (свернутая в трей Dota не
  детектируется).
- Уведомление «матч найден» опирается на детектор кнопки «Принять», а не на Steam:
  Steam Web API не документирует момент accept-экрана и фиксирует матч только после
  входа в игру.
- Принять матч можно кнопкой из уведомления (локальный `Enter`), но только на ПК с
  запущенной Dota 2; автоматического принятия без действия пользователя нет.
- Отклонить матч из бота нельзя: для этого нужен клик по кнопке Decline.
- Составы и любимые герои появляются на OpenDota через несколько минут после матча.
  На каждый матч уходит ~11 запросов (детали + 10 игроков), результаты кешируются на
  6 часов; при частых играх возможен лимит OpenDota (60 запросов/мин).
