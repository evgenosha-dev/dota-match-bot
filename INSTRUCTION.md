# Инструкция для нового пользователя

Скачать и запустить бота за 5 минут. Никакого редактирования кода не нужно.

## 1) Скачать
Вариант A — готовый `.exe` (рекомендуется, Windows)
1. Открой [Releases](../../releases) этого репозитория
2. Скачай `dota-match-bot.exe` из последнего релиза
3. Положи его в отдельную папку, например `C:\Tools\dota-match-bot\`

Вариант B — из исходников
1. Установи [Python 3.12](https://www.python.org/downloads/)
2. Скачай архив репозитория (Code → Download ZIP) или клонируй через git
3. Распакуй в отдельную папку

## 2) Первичная настройка
### Если у тебя `.exe`
1. Запусти `dota-match-bot.exe` двойным кликом
2. Откроется мастер настройки в консоли

### Если из исходников
```powershell
cd "C:\путь\к\dota-match-bot"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python bot.py setup
```

Мастер по шагам спросит:

1. **Telegram**
   - Открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя → скопируй токен вида `123456789:AA...`
   - Вставь токен в консоль
   - Напиши боту любое сообщение в Telegram и нажми `Enter` — бот сам найдёт твой `chat_id`

2. **Steam** (необязательно, но сильно рекомендовано)
   - Ключ: [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey)
   - Профиль: ссылка вида `https://steamcommunity.com/profiles/76561198.../` или просто `76561198...`
   - Можно просто нажать `Enter`, чтобы пропустить

3. **GSI** (рекомендуется)
   - Если Dota 2 установлена — мастер найдёт её сам и запишет конфиг
   - После настройки **перезапусти Dota 2**

4. **Автопринятие матча**
   - Нажми `Y`, если хочешь кнопку `Принять матч` в уведомлении Telegram
   - Работает только если бот запущен на том же ПК, где Dota 2

После мастера в той же папке появится `config.json`. Настройка закончена.

## 3) Запуск
### `.exe`
Двойной клик по `dota-match-bot.exe`. Окно можно свернуть.

### Из исходников
```powershell
python bot.py run
```

Готово. Как только найдётся матч — придёт уведомление в Telegram с кнопкой принятия (если включена). По завершении матча придёт отчёт с составами обеих команд и топ-3 героями за 50 игр.

## 4) Автозапуск при включении ПК
### `.exe`
Нажми `Win+R` → `shell:startup` → кинь ярлык `dota-match-bot.exe` в эту папку.

### Из исходников
Создай ярлык с параметрами:
- Программа: `C:\путь\к\dota-match-bot\.venv\Scripts\pythonw.exe` (чтобы без консоли) или `python.exe`
- Аргументы: `bot.py run`
- Рабочая папка: `C:\путь\к\dota-match-bot`

## Советы
- **Dota не в фокусе** — для лучшей работы детектора окна включи в Dota `Настройки → Параметры → Доп. параметры → Выводить Dota 2 на передний план при поиске матча`
- **Только свой бот** — у каждого должен быть свой токен от `@BotFather`. Твой токен использовать нельзя
- **Всё локально** — `config.json` хранится только у тебя, токены никуда не улетают
- **Уведомления не спамят** — пока ты в игре, повторных «Матч найден» не будет. Если матч отменили/не приняли — через ~4 минуты придёт новое, когда начнётся следующий поиск

## Команды для справки
```powershell
python bot.py run      # запуск
python bot.py setup    # изменить/дополнить настройки
python bot.py test     # проверить отправку сообщения
python bot.py status   # посмотреть статистику
```
